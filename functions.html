الدوال (Functions) - مصانع الأكواد

أهم قاعدة في هندسة البرمجيات هي (لا تكرر نفسك - DRY: Don't Repeat Yourself). إذا كان لديك كود معقد يحسب الضرائب وتحتاج لاستخدامه في 50 مكان مختلف في برنامجك، نسخ الكود ولصقه يعتبر جريمة برمجية!
الحل هو وضع هذا الكود داخل دالة (Function) وإعطاؤه اسماً، ثم مناداته متى شئت.

بناء مصنعك الأول

لتعريف دالة جديدة نستخدم الكلمة المحجوزة def (اختصار Define)، تليها اسم الدالة وأقواس. الكود بداخلها (المسافة البادئة) لن يتنفذ أبداً إلا إذا قمت باستدعاء الدالة (Calling it).

المواد الخام والإنتاج (Parameters & Return)

الدالة مثل المصنع تماماً: قد تحتاج إلى مواد خام لتصنيعها (Parameters تُمرر في الأقواس)، وقد تعطيك منتجاً نهائياً (تستخدم كلمة return لترجيعه لك).

def add_numbers(x, y):  # x و y هي المواد الخام التي يستقبلها المصنع
    answer = x + y
    return answer       # المصنع ينهي عمله ويرجع لك النتيجة

# استدعاء المصنع وإعطاؤه المواد الخام (5 و 10)
result = add_numbers(5, 10) 
print(result)           # سيطبع 15

لماذا نستخدم Return بدلاً من Print داخل الدالة؟

دالة print تعرض النص على الشاشة فقط للعين البشرية، لكن الكمبيوتر لا يستطيع استخدام هذه النتيجة لاحقاً. بينما return تعيد القيمة فعلياً لكي تخزنها في متغير وتكمل عليها عمليات حسابية أخرى. بمجرد أن يصل بايثون لكلمة return يتوقف فوراً ويخرج من الدالة.

تمرين عملي 🚀

تم إعداد قالب لدالة اسمها multiply (الضرب). مهمتك هي إكمال المصنع:

  1. داخل الدالة، استخدم return لإرجاع حاصل ضرب المعامل a في المعامل b (استخدم علامة * للضرب).

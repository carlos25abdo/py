الصفوف (Tuples) والمجموعات (Sets)

عرفنا القوائم (Lists) التي تستخدم الأقواس المربعة [] والقواميس (Dicts) التي تستخدم {}. بايثون يوفر لنا نوعين آخرين من البيانات لكل منهما استخدام خاص ومهم.

1. الصفوف (Tuples) - القوائم المحمية

الـ Tuple هو بالضبط مثل القائمة (List)، لكن لا يمكن تغييره أبداً بعد إنشائه! (لا يمكن إضافة، حذف، أو تعديل عناصره). يستخدم لحماية البيانات الحساسة مثل الإحداثيات الجغرافية أو أيام الأسبوع.

كيف نكتبها؟ نستخدم الأقواس الدائرية ()

dimensions = (1920, 1080)
print(dimensions[0]) # سيطبع 1920

# dimensions[0] = 800  <-- هذا السطر سيسبب خطأ لأن Tuples لا تتغير!

2. المجموعات (Sets) - البيانات الفريدة

الـ Set هو مجموعة لا تسمح بالتكرار إطلاقاً ولا تهتم بالترتيب. ممتاز جداً إذا كان لديك قائمة بها أسماء مكررة وتريد تصفيتها واستخراج الأسماء الفريدة فقط.

كيف نكتبها؟ نستخدم الأقواس المتعرجة {} بدون مفاتيح!

numbers = {1, 2, 2, 3, 4, 4, 4, 5}
print(numbers) # سيطبع {1, 2, 3, 4, 5} لقد تم حذف المكرر تلقائياً!
